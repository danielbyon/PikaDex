Last Resort (move)

Move data

Type Normal
Category   Physical
Power 140
Accuracy 100
PP 5  (max. 8)
Introduced Generation 4

Effects

Last Resort deals high damage, but will fail if the user has not used each of its other moves at least once (or has no other moves). If the user switches out, the move gets reset and when it switches back in, will need to use each of its other moves at least once in order to use Last Resort again.

Changes

In Generations 1-4, Last Resort has a base power of 130.

Z-Move effects

When a Pokémon is holding Normalium Z and uses its Z-Power, Last Resort turns into Breakneck Blitz and has base power 200.

When Eevee is holding Eevium Z and uses its Z-Power, Last Resort turns into Extreme Evoboost.
