Move data

Type Normal
Category   Physical
Power —
Accuracy 100
PP 15  (max. 24)
Introduced Generation 2

Effects

Flail deals more damage the lower the user's HP. The following formula is used:

N = 48 × CurrentHP ÷ MaxHP

The value of N is then used to determine the base power, as per the table below. It converts to some quite specific percentages which are also shown.

Ratio (N)HP (%)Power
0 ≤ N < 20 - 4.16200
2 ≤ N < 44.17 - 10.41150
5 ≤ N < 910.42 - 20.82100
10 ≤ N < 1620.83 - 35.4180
17 ≤ N < 3235.42 - 68.7440
33 ≤ N ≤ 4868.75 - 10020

Changes

In Generations 2-4, Flail used a multiplier of 64 instead of 48. The table below shows the appropriate numbers.

Ratio (N)HP (%)Power
0 ≤ N < 20 - 3.12200
2 ≤ N < 63.13 - 9.35150
6 ≤ N < 139.36 - 20.30100
13 ≤ N < 2220.31 - 34.3780
22 ≤ N < 4334.38 - 67.1840
43 ≤ N ≤ 6467.19 - 10020

Z-Move effects

When a Pokémon is holding Normalium Z and uses its Z-Power, Flail turns into Breakneck Blitz and has base power 160.
