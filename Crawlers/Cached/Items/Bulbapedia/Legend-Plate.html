The Legend Plate (Japanese: レジェンドプレート Legend Plate) is a Key Item in Pokémon Legends: Arceus. It is one of the Plates, which are associated with Arceus.

The following inscription is engraved: "From all creations, over all creations, does the Original One watch over all."

In the core series games

Effect

When used on Arceus, the Legend Plate changes it to the Normal type, like the Blank Plate.

In battle, Arceus gains the ability to change type when using Judgment, based to the opponent's type. Specifically, it will pick a type that the target is weak to, prioritizing double weakness for dual-types. While selecting a move, Judgment will appear as the type that it will turn to if used that turn. This is similar to Unown's signature move Hidden Power.

The Legend Plate also has a secondary priority of picking types according to defensive matchup against the target's types. For example against a Rock/Ground it will pick Grass as it is effective against both its types and resists its Ground type, unlike Water. If multiple types are valid, such as against a pure Fighting-type, it will pick at random. Arceus can even change which type it is against the same target, as the most optimal type is recalculated every single turn.

Outside of battle, Arceus's type is reverted to Normal.

Description

Games Description
LA A stone tablet imbued with the essence of all creation. When used on a certain Pokémon, it allows that Pokémon to gain the power of every type there is.

Acquisition

Games Method
LA Hall of Origin (reward for defeating Arceus)

Trivia

  • Due to the way the Legend Plate operates, using Judgment will never turn Arceus to a Normal type (as nothing is weak to it).
