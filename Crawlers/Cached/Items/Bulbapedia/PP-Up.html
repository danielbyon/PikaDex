The PP Up (Japanese: ポイントアップ Point Up) is a type of vitamin introduced in Generation I. It raises the PP of a selected move by 1/5 of the move's base PP.

The PP Max is an improved version of this item.

Effect

When used from the Bag on a Pokémon, raises the PP of a selected move by 1/5 of the move's base PP, until 3 PP Ups or one PP Max have been used on the Pokémon's move. It cannot be used on Sketch.

The PP Up is consumed upon use and cannot be used in battle.

Generations I to II

If used on a move with 40 base PP, each PP Up will only add 7 PP (up to 61 PP if three PP Ups are used). This is due to limitations in the Pokémon data structure in these games, which cannot store PP values greater than 63.

Generation III onward

If used on a move with 40 base PP, it will add 8 PP (up to 64 PP if three PP Ups are used), consistent with the formula for other moves.

The PP Up also increases the Pokémon's friendship a little.
