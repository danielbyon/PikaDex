TM Material

From Bulbapedia, the community-driven Pokémon encyclopedia.
Jump to navigationJump to search
Sprite from Pokémon Scarlet and Violet

TM Materials are a category of items introduced in Generation IX. They are primarily used to create TMs, each of which require a specific set of TM Materials to be made.

In the core series games

Effect

TM Machine

In Pokémon Scarlet and Violet, TM Materials can be used in combination with each other and League Points at the TM Machine in a Pokémon Center to create TMs. They can also be exchanged at the TM Machine for League Points.

Some TM Materials are not included in any TM recipes. These include all the ones from version-exclusive Pokémon, along with Ditto, Rotom, Cyclizar, and Gimmighoul:

  • Ditto Goo
  • Misdreavus Tears
  • Larvitar Claw
  • Gulpin Mucus
  • Bagon Scales
  • Drifloon Gas
  • Stunky Fur
  • Rotom Sparks
  • Deino Scales
  • Skrelp Kelp
  • Clauncher Claw
  • Oranguru Fur
  • Passimian Fur
  • Stonjourner Stone
  • Eiscue Down
  • Dreepy Powder
  • Cyclizar Scales
  • Gimmighoul Coin

Other uses

Some TM Materials have other uses, beyond being used to create TMs.

  • Bronzor Fragment: 10 can be used to create Auspicious ArmorS
  • Sinistea Chip: 10 can be used to create Malicious ArmorV
  • Gimmighoul Coin: If the player has 999 Gimmighoul Coins, Gimmighoul evolves into Gholdengo when it levels up

Description

All TM Materials, except Gimmighoul Coins, share the same description.

Games Description
SV Material accidentally dropped by a Pokémon. It can be used to make TMs.

Acquisition

In Pokémon Scarlet and Violet, TM Materials (except Gimmighoul Coins) are dropped by wild Pokémon upon being defeated or captured, with the type of TM Material being based on the Pokémon's corresponding evolutionary family. The amount dropped can be increased for a specific type of Pokémon by eating a food item with the Item Drop Power.

Gimmighoul Coins can be obtained by interacting with Gimmighoul in the overworld.

Additionally, some TM Materials can be obtained as gifts in-game.
