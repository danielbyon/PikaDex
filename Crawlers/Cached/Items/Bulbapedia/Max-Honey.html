Max Honey (Japanese: ダイミツ Dai Honey) is an item that was introduced in Generation VIII. It is a type of honey produced by Dynamax Vespiquen.

In the core series games

Price

Games Cost Sell price
SwSh N/A 4,000

Effect

When used from the Bag on a fainted Pokémon, it revives the Pokémon and restores all of the Pokémon's HP.

Additional effect

Required as an additional Max Soup ingredient to give or remove Urshifu's Gigantamax Factor.

Description

Games Description
SwSh Honey that Dynamax Vespiquen produces. Adding this honey to Max Soup makes the taste very smooth. It also has the same effect as a Max Revive.

Acquisition
