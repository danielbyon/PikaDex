Seed Bomb (Japanese: タネばくだん Seed Bomb) is a damage-dealing Grass-type move introduced in Generation IV. It is TR59 in Generation VIII.

Effect

Seed Bomb inflicts damage and has no secondary effect. It does not affect targets with Bulletproof.

Seed Bomb can be used as part of a Contest Spectacular combination with the user gaining an extra three appeal points if Rototiller was used in the prior turn.
