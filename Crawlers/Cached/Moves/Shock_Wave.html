Shock Wave (Japanese: でんげきは Electrical Shock Wave) is a damage-dealing Electric-type move introduced in Generation III. It was TM34 from Generation III to Generation IV.

Effect

Shock Wave inflicts damage and bypasses accuracy checks to always hit, unless the target is in the semi-invulnerable turn of a move such as Dig or Fly.

Shock Wave can be used as part of a Pokémon Contest combination, with the user gaining extra two appeal points if Charge was used in the prior turn. It is also part of a Contest Spectacular combination, with the user gaining an extra three appeal points if Charge was used in the prior turn.
