Chilling Water (Japanese: ひやみず Cold Water) is a damage-dealing Water-type move introduced in Generation IX. It is TM022 in Generation IX.

Contents

  • 2 Description
  • 3 Learnset
    • 3.1 By TM
  • 4 In other languages

Effect

Chilling Water inflicts damage and lowers the target's Attack by one stage.

Description

Games Description
SV The user attacks the target by showering it with water that's so cold it saps the target's power. This also lowers the target's Attack stat.
