Pounce (Japanese: とびつく Pounce) is a damage-dealing Bug-type move introduced in Generation IX. It is TM021 in Generation IX.

Contents

  • 2 Description
  • 3 Learnset
    • 3.1 By TM
  • 4 In other languages

Effect

Pounce inflicts damage and lowers the target's Speed by one stage.

Description

Games Description
SV The user attacks by pouncing on the target. This also lowers the target's Speed stat.
