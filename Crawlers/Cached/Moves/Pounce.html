Pounce (Japanese: とびつく Pounce) is a damage-dealing Bug-type move introduced in Generation IX. It is TM021 in Pokémon Scarlet and Violet.

Effect

Pounce inflicts damage and lowers the target's Speed by one stage.

Description

Games Description
SV The user attacks by pouncing on the target. This also lowers the target's Speed stat.
