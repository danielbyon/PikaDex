Imprison (Japanese: ふういん Seal) is a non-damaging Psychic-type move introduced in Generation III. It is TM44 in Generation VIII.

Effect

Generations III and IV

As long as the user remains in battle, opponents cannot use any move which is also known by the user (including Pokémon switched in after the move was used). If the user's moveset changes while Imprison is in effect (such as by Mimic, Sketch, Transform, or learning a new move by leveling up), opponents are prevented from using the new moves.

On the turn that Imprison is used, if an opposing Pokémon would move after Imprison is used and it selected a move the user knows that turn, it will be unable to use that move and make no action that turn (i.e. PP for that move is not consumed). If a Pokémon has no moves with PP other than moves prevented by Imprison, it will Struggle.

Imprison will fail if no opponent possesses a move the user knows at the time Imprison is used.

Imprison cannot be passed by Baton Pass.

Generations V to VII

Imprison will still execute even if no opponent has a move the user knows; although Imprison has no immediate effect in such a case, if the user or opponents change the moves they know (e.g. Mimic, Sketch, Transform, or learning a new move by leveling up) or a different opposing Pokémon enters the battle, it will be prevented from using the user's moves.

In Triple Battles, non-adjacent opponents are prevented from using moves that the user knows.

Imprison can now be stolen by Snatch.

If powered up by a Psychium Z into Z-Imprison, the user's Special Defense stat is raised by two stages.

Generation VIII

Even though Imprison can be used in Max Raid Battles, the raid boss is immune to Imprison's effect.

In other games

Pokémon Mystery Dungeon series

In Red Rescue Team and Blue Rescue Team and Explorers of Time, Darkness and Sky, Imprison is a move with 15PP. The user targets enemy in front, and inflicts Paused status condition on target for 5-12 turns, making them incapable of action. This move is affected by Taunt.

From Gates to Infinity onward, all enemy Pokémon on the floor cannot use any move which is also known by the user.

Description

Games Description
MDRB Inflicts the Paused status on the target, making it incapable of action.
MDTDS Afflicts the targeted enemy with a Paused status condition. A Pokémon with the Paused status is incapable of action.

MDGtI If enemies on the same floor know any moves also known by you, it seals them and prevents all enemies from using the moves.
SMD If enemies on the same floor know any moves you also know, it has them sealed, preventing all enemies from using the moves.

Trivia

  • The kanji featured in Imprison's Japanese animations is 封, which is the first kanji of 封印 (ふういん Fūin (Seal)), which is its Japanese name.
  • In Generation III, the status screen erroneously states that the move has 100% accuracy, even though it targets the user (thus it ignores accuracy and evasion checks).
