Trailblaze (Japanese: くさわけ Trailblazer) is a damage-dealing Grass-type move introduced in Generation IX. It is TM020 in Pokémon Scarlet and Violet.

Contents

  • 1 Effect
  • 2 Description
  • 3 Learnset
    • 3.1 By TM
  • 4 In other languages

Effect

Trailblaze inflicts damage and raises the user's Speed by one stage.

Description

Games Description
SV The user attacks suddenly as if leaping out from tall grass. The user's nimble footwork boosts its Speed stat.
