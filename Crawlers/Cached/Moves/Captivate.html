Captivate (Japanese: ゆうわく Allure) is a non-damaging Normal-type move introduced in Generation IV. It was TM78 in Generation IV.

Effect

Generations IV to VII

Captivate lowers the Special Attack stat of the target by two stages, if it is the opposite gender of the user. It targets all adjacent opponents. Gender-unknown Pokémon (such as Magnemite) and Pokémon with the Ability Oblivious are unaffected by this move. It always does nothing if the user of Captivate is a gender-unknown Pokémon.

If powered up by a Normalium Z into Z-Captivate, the user's Special Defense stat is raised by two stages.

Generation VIII

Captivate cannot be selected in a battle.

In other games

Pokémon Mystery Dungeon series

In Explorers of Time, Darkness and Sky, Captivate is a move with 20PP that ignores accuracy and evasion checks. The user targets enemy in front of it, lowering their Special Attack by 2 stages. This move works only if the user is the opposite gender of the target. This move is affected by Taunt and Magic Coat.

The gender mechanic was removed in Gates to Infinity onwards, meaning the move works on all Pokémon.

Trivia

  • Mew is the only Pokémon with unknown gender that can learn this move: Mew is able to learn any TM, and can learn it by TM78 in Generation IV.
  • It is likely that Nincada cannot learn Captivate because all moves a Nincada has are transferred to a shed-off Shedinja when it evolves into Ninjask, thus giving the gender-unknown Shedinja a useless move. The same is the case with Attract.
