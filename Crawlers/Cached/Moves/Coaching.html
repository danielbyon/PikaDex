Coaching (Japanese: コーチング Coaching) is a non-damaging Fighting-type move introduced in Generation VIII.

Contents

  • 1 Effect
  • 2 Description
  • 3 Learnset
    • 3.1 By Move Tutor
  • 4 In other languages

Effect

Coaching boosts the Attack and Defense of all allies (but not the user) by one stage each. It bypasses all forms of protection to affect the allies, including Crafty Shield.

If used in a Single Battle or when no ally is present, Coaching will fail.

Description

Games Description
SwSh The user properly coaches its ally Pokémon, boosting their Attack and Defense stats.
BDSP This move can’t be used. It’s recommended that this move is forgotten. Once forgotten, this move can’t be remembered.
