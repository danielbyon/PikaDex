Spite (Japanese: うらみ Spite) is a non-damaging Ghost-type move introduced in Generation II.

Effect

Generation II

Spite will lower the PP of the last move the target used. The number of PP lost is selected randomly between 2 and 5 (or all of the remaining PP, if that is less).

Spite will fail if the targeted move has no PP remaining.

Spite can also be used as part of a Pokémon Contest combination, with the user gaining an extra appeal point if move Curse was used in the prior turn.

Generation III

Spite will also fail if the targeted move has 1 PP remaining.

Generation IV

Spite will now deduct 4 PP from the last move that the target used.

Spite no longer fails if the targeted move has exactly 1 PP remaining (it only fails if the move has no PP remaining).

Generation V onwards

Spite can now be reflected with Magic Coat.

Spite can also be used as part of a Contest Spectacular combination, with the user gaining extra three appeal points if any of the moves Encore, Taunt or Torment was used in the prior turn.

If powered up by a Ghostium Z into Z-Spite, the user regains all of its HP.

In other games

Pokémon Mystery Dungeon series

Prior to Gates to Infinity, Spite deducted all PP from the target's last used move, instead of just 4. In Pokémon Super Mystery Dungeon, Spite deducts 20 PP from the target's last used move.

Description

Games Description
MDRB Zeroes the PP of the move last used by the target, making it unusable.
MDTDS Zeroes the PP of the move last used by the target.
BSL てきポケモンが さいごにくりだしたわざの ＰＰを ０にして つかえなくしてしまう
MDGtI It sharply lowers the PP of the move last used by the enemy.
SMD It sharply lowers the PP of the move last used by the enemy. It fails if the enemy had not used a move or if the enemy's PP is already 0.
