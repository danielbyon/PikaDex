Retaliate (Japanese: かたきうち Retaliation) is a damage-dealing Normal-type move introduced in Generation V. It is TM67 in Generations V and VI.

Effect

Retaliate inflicts damage. Its base power doubles from 70 to 140 if a Pokémon from the user's party has fainted in the previous turn.

Description

Games Description
BWB2W2 The user gets revenge for a fainted ally. If an ally fainted in the previous turn, this attack's damage increases.
XYORAS The user gets revenge for a fainted ally. If an ally fainted in the previous turn, this move becomes more powerful.
SMUSUM The user gets revenge for a fainted ally. If an ally fainted in the previous turn, this move's power is increased.
